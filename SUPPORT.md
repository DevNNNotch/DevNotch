# Support

Use GitHub Discussions for setup questions, integration design, and general help. Use an issue only for reproducible defects or accepted implementation work.

Before requesting help:

1. Read `README.md`, `docs/LOCAL_API.md`, and `docs/IMPLEMENTATION_STATUS.md`.
2. Search existing issues and discussions.
3. Include the DevNotch version, macOS version, hardware architecture, and exact error message.

Never post API keys, local API tokens, clipboard contents, or private source code. Report security issues privately as described in `SECURITY.md`.
