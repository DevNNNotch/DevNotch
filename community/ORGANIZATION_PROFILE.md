# DevNotch Community

DevNotch is an open-source community building a native macOS developer surface around the notch and menu bar.

We focus on observable developer work: AI token telemetry, local model health, build and task progress, logs, clipboard-assisted debugging, and system status. Integrations must use official or user-authorized structured data. Unknown values remain unavailable rather than being estimated.

## Start here

- **DevNotch** contains the macOS application and local event API.
- **Discussions** is the place for setup questions, provider research, and design proposals.
- **Issues** track reproducible defects and accepted implementation work.
- **Security reports** follow the private process in `SECURITY.md`.

The project is derived from Boring Notch and distributed under GPL-3.0. We welcome focused code, documentation, accessibility work, and provider adapters backed by testable sources.
